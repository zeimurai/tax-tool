使用上の注意

Taxumoは、以下の学生ビザで米国に滞在している「非居住者（nonresident alien）」の学生向けに設計されたForm 8843作成サポートツールです：

Taxumoの対象者

  • F-1 / F-2（学生およびその家族）
  • M-1 / M-2（職業訓練学生およびその家族）
  • J-1 / J-2（※学生カテゴリーに該当する場合のみ）

以下のいずれかに該当する方は、Taxumoの対象外であり、Form 8843の提出が不要または不適切な可能性があります。

Taxumoをご利用いただけないケース一覧

  • ビザ上はF/M/Jでも、税法上「非居住者ではない」場合
    • 米国市民または居住者（グリーンカード保有者など）と結婚し、MFJ（Married Filing Jointly）を選択した
    • グリーンカード（永住権）を取得済み
    • Substantial Presence Test（SPT）を満たし、非居住者ではなくなった
    • 既に税法上の居住者（Resident Alien）としてForm 1040で申告済み
  • 対象ビザに該当しない、または学生以外の目的で滞在している場合
    • J-1 / J-2ビザのうち、教師・研究者・研修生カテゴリーの方（→Form 8843のPart II対象ですが、Taxumoは対応していません）
    • H-1Bなどの就労ビザ保持者
    • OPT後にF-1以外のビザに変更した方
    • その他、学生でない目的での滞在者（Qビザなど）
  • Fビザでの滞在が5暦年を超え、SPTの除外対象でなくなった方
    • 原則として、F-1/F-2ビザでの滞在は最初の5暦年間までがSPT除外対象です
    • 6年目以降は居住者扱いとなる可能性があり、Form 8843の提出対象外となる場合があります
